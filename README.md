# SkatAI V2

Clean-slate Skat AI research and engineering project.

Primary objective: maximize reproducibly accepted, deployment-valid real-world Skat playing strength per useful compute and wall-clock time.

Founding constraints:
- V2 is not a continuation or refactor of V1.
- V1 is forensic/reference-only.
- V2 inherits verified evidence, not architecture or runtime state.
- SkatZero is frozen as the initial B0 baseline.
- The first causal strength experiment is learned bidding with cardplay frozen.
